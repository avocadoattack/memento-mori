FIX 2 — EQUAL ROWS PER DECADE

Currently some decades render 4 rows and some render 5, because the column count doesn't divide
evenly into 520 (10 years × 52 weeks).

Fix: calculate colCount so that 520 is exactly divisible by it:
  - Compute the maximum number of columns that fit in the available canvas width:
    maxCols = Math.floor(availableWidth / (SQUARE_SIZE + GAP))
  - Then find the largest value ≤ maxCols where (520 % value === 0):
    const candidates = [130, 104, 65, 52, 40, 26, 20, 13, 10, 8, 5, 4, 2, 1]
    colCount = candidates.find(c => c <= maxCols) ?? 52
  - This guarantees every decade = exactly 520/colCount rows (no decade gets an extra row)
  - Recompute canvas height from the new colCount
