You are building a complete, production-quality single-page web app in React + Vite called **Memento Mori: Time Audit** — a darkly motivational interactive calculator that shows how little discretionary time a person actually has in their lifetime after subtracting obligatory and habitual activities.

---

## TECH STACK

- React + Vite
- GSAP (GreenSock) for all animations — install via npm
- Tailwind CSS for layout and utilities
- lucide-react for icons
- No backend. No database. All state is in-memory React state.

---

## THEME SYSTEM

Implement dual light/dark theming using this priority chain:
1. Request the browser's Geolocation API on load.
2. If granted: calculate local sunrise and sunset using the SunCalc algorithm (hardcode the math inline — no external library). Switch to dark mode after sunset, light before sunrise.
3. If denied or times out after 3s: fall back to `prefers-color-scheme`.
4. Always show a manual sun/moon toggle button in the top-right corner.
5. All color transitions: 0.4s CSS ease on background, text, and border colors.

## LAYOUT

Three-panel layout on desktop (≥1024px), stacked single column on mobile.

### 1. HERO SECTION (top, full width)

Large bold headline: "YOUR LIFE IN WEEKS"
Subhead: "After sleep, work, and everything else — here's what's actually left."

Below that: a real-time **Countdown to Death** clock. This is the most visceral element — make it prominent. It shows:

`[Y] years  [M] months  [W] weeks  [D] days  [H] hours  [Min] minutes  [S] seconds`

Calculate it as: (birth date derived from current age + life expectancy) minus now. Tick every second using setInterval. Animate seconds with a GSAP flip/fade on each tick. Style it like a dramatic countdown clock — large monospace numerals, slight red tint.

Below the countdown: a secondary GSAP-animated counter: "Free Hours Remaining: [X,XXX,XXX]" that updates in real time as inputs change.

### 2. LIFE GRID (center panel)

A grid where each square = 1 week of life. Total squares = life expectancy × 52.
- Each square is 7×7px with 1.5px gap, sharp corners (no border radius).
- Color each square with the dominant time category for that week (use proportional logic — whichever category consumes the most hours in that life stage owns the square color).
- Past weeks (age already lived) render desaturated/faded at 25% opacity.
- The current week pulses with GSAP (scale 1→1.12→1, yoyo, repeat, 2s duration).
- On hover: tooltip showing "Week [N] · Age [X] · [Y]h free this week".
- On load: squares stagger in with GSAP from opacity 0, left-to-right, top-to-bottom, 0.003s delay per square.

### 3. CONTROLS PANEL (right sidebar on desktop, below grid on mobile)

Sliders with live numeric inputs. Group visually with bold section headers.

## STATS PANEL (below the grid, full width — 4-column card grid)

Each stat is a card with a large animated number + small label. Use GSAP CountTo (0.6s ease) whenever any input changes.

Cards to show:
1. **Total Life Hours** — lifeExpectancy × 365.25 × 24
2. **Sleeping** — sleepHours × 365.25 × lifeExpectancy
3. **Working** — workHours/week × 52 × (retirementAge − workStartAge)
4. **In School** — schoolYears × 180 × schoolHoursPerDay
5. **Eating & Cooking** — eatingHours × 365.25 × lifeExpectancy
6. **Grooming** — groomingHours × 365.25 × lifeExpectancy
7. **Chores** — choresHours × 365.25 × lifeExpectancy
8. **Commuting** — commuteHours × 260 × (retirementAge − workStartAge)
9. **Social Media** — socialMediaHours × 365.25 × lifeExpectancy
10. **Passive TV** — tvHours × 365.25 × lifeExpectancy
11. **TOTAL TAKEN** — sum of cards 2–10 (bold, red tint)
12. **FREE HOURS** — Total − Total Taken (largest card, accent color, most prominent)
13. **FREE YEARS** — Free Hours ÷ 8760
14. **FREE WEEKS** — Free Hours ÷ 168
15. **% Life That's Yours** — Free Hours ÷ Total Life Hours × 100

If Free Hours goes negative: show a red banner warning "Your habits leave you with no free time. Something has to give." Do not crash the UI.

## ANIMATIONS (GSAP)

- Load: hero countdown and free hours counter animate in over 2.5s with ease-out
- Life grid: squares stagger in from opacity 0 with 0.003s per square delay, left-to-right wave
- Current week: slow pulse (scale 1 → 1.12 → 1, yoyo, repeat, 2s)
- Countdown seconds: GSAP flip/fade transition on each tick (the seconds digit "rolls over")
- Slider changes: all stat numbers GSAP CountTo new values over 0.6s
- If % drops below 10%: red glow pulse on FREE HOURS card (GSAP repeat)
- Light/dark toggle: GSAP 0.4s color fade across all tokens
- Stat cards: hover → translateY -4px + deeper box-shadow (GSAP quickTo)
- Country/gender change: life expectancy field fades out old value, fades in new one (GSAP 0.3s)

- Fonts: Load "Space Grotesk" (headings, numbers, countdown) + "Inter" (body, labels, tooltips) from Google Fonts
- Typography: Hero countdown 64px monospace bold · Free hours 48px bold · Section heads 22px semibold · Stat card numbers 36px bold · Labels 12px uppercase tracking-widest
- Grid squares: 7×7px, 1.5px gap, zero border radius — sharp and dense
- Cards: dark bg in dark mode, white in light mode, 8px radius, no border
- Sliders: custom-styled — track fill in each category's color, thumb is a clean white circle with shadow
- Overall aesthetic: data journalism editorial — urgent, clean, no decorative fluff. Every element earns its place.
- No gradients on text. No glassmorphism. Sharp contrast only.
