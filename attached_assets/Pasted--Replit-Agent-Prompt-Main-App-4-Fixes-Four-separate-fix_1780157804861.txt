# Replit Agent Prompt — Main App: 4 Fixes

Four separate fixes to the main app page. Do them all in one pass. Do not change any calculation logic in `useLifeCalc.ts` except where explicitly instructed below.

---

## TASK 1 — Scroll chevron visibility

The animated scroll chevron (ChevronDown icon) at the bottom of the hero section is being clipped/cut off on laptop screens (~900px viewport height). The root cause is likely the hero section overflowing or the chevron being positioned outside the `--dvh` boundary.

Fix: ensure the hero section is exactly `100dvh` (using the `--dvh` CSS custom property already set on mount), that `overflow: hidden` is NOT applied to it, and that the chevron is the last item in the hero flex column with no negative margin or absolute positioning pushing it out of frame. The chevron should always be fully visible without scrolling on any screen ≥ 768px tall.

## TASK 3 — Life grid: fix centering + decade labels

The canvas grid is not horizontally centered and the decade age labels (10, 20, 30...) are misaligned.

Restructure the grid layout to use **one row per year** (52 squares per row), grouped into decades (10 rows per decade group). This simplifies the column math completely:

- `cols = 52` (fixed, not computed from container width)
- `rows = Math.ceil(lifeExpectancy)` total rows, one per year of life
- Each decade group = 10 rows with a small gap between groups
- Age labels (10, 20, 30, 40, 50, 60, 70, 80) rendered as HTML `<span>` elements to the LEFT of their decade group, vertically centered in the 10-row block — NOT as canvas text
- The canvas itself should be centered in its container via `display: block; margin: 0 auto`
- `ResizeObserver` should set the canvas `width` to the container's `clientWidth`, and canvas height should be computed from the fixed row/gap math — not the other way around
- Apply `devicePixelRatio` scaling as before
- Past weeks: same base color + red X via `ctx.stroke()`. Current week: accent border + pulse. Future: base color only.
