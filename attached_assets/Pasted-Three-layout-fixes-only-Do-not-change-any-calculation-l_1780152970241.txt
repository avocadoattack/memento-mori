FIX 3 — LIFE GRID: CLEAR SEPARATION FROM HERO, PROPER CENTERING

The grid section is overlapping the hero cards because:
a) The `#life-grid` section has no top margin/padding separating it from what's above
b) The `width: fit-content` on the canvas wrapper may not center correctly in all containers

```tsx
  }}>
    <canvas ref={canvasRef} />
    {/* decade label spans and coffin emoji overlay here */}
  </div>
</section>
```

Also in LifeGrid.tsx, when computing canvas display width:
  Use the section's inner width minus paddingLeft/paddingRight as the available width,
  NOT window.innerWidth. Pass it via a ref or ResizeObserver on the section element.
  This prevents the canvas from being wider than its container and overflowing.

```tsx
// In LifeGrid.tsx — observe actual container width
const containerRef = useRef<HTMLDivElement>(null);
const [availableWidth, setAvailableWidth] = useState(800);

useEffect(() => {
  if (!containerRef.current) return;
  const ro = new ResizeObserver(entries => {
    setAvailableWidth(entries[0].contentRect.width);
  });
  ro.observe(containerRef.current);
  return () => ro.disconnect();
}, []);
```

Use `availableWidth` (not `window.innerWidth`) everywhere the canvas width is calculated.
