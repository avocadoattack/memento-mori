CHANGE 5 — DECADE LABELS: FIX FUZZY RENDERING

The decade age labels (10, 20, 30…) drawn on the canvas are blurry.
Fix by ensuring the canvas is sized for device pixel ratio:

At canvas initialization:
```js
const dpr = window.devicePixelRatio || 1;
canvas.width = displayWidth * dpr;
canvas.height = displayHeight * dpr;
canvas.style.width = displayWidth + 'px';
canvas.style.height = displayHeight + 'px';
ctx.scale(dpr, dpr);
```

Also for the decade labels specifically:
- Use `ctx.font = 'bold 11px -apple-system, BlinkMacSystemFont, sans-serif'` (system font renders crisper than generic sans-serif)
- Add `ctx.imageSmoothingEnabled = false`
- Use `Math.round()` on ALL text x/y coordinates before calling ctx.fillText()
