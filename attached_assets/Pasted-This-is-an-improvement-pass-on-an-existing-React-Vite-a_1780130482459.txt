This is an improvement pass on an existing React + Vite app called Memento Mori: Time Audit. Do NOT rebuild from scratch. Apply only the changes listed below. Preserve all existing calculation logic, the life expectancy lookup table, the IP geolocation, and the countdown timer.

## CHANGE 1 — REMOVE GSAP ENTIRELY

Uninstall GSAP. Replace every animation with one of these:
- CSS transitions (color, opacity, transform) — use `transition: all 0.25s ease` where smooth changes are needed
- `requestAnimationFrame` loop for the countdown ticker (already ticks per second — no animation library needed)
- CSS `@keyframes` for the current-week pulse on the grid
- A lightweight custom `countTo(start, end, duration, onUpdate)` function using `requestAnimationFrame` for the stat card number animations — implement this as a ~15-line vanilla JS utility, no library

This is the primary performance fix. The grid re-rendering 4,000+ nodes through GSAP is the bottleneck.

---

## CHANGE 2 — GRID PERFORMANCE: VIRTUALIZE OR USE CANVAS

The life grid is the main bottleneck. Replace the DOM-based grid with an HTML5 `<canvas>` element. Draw all squares using the 2D canvas API:
- Each square: 7×7px, 1.5px gap
- Color logic unchanged — use the same category color priority per week
- Past weeks: draw at 30% opacity
- Current week: CSS `@keyframes` pulse is NOT possible on canvas — instead, use `requestAnimationFrame` to redraw just the current week square with a subtle scale/glow effect each frame
- Hover tooltip: track `mousemove` on the canvas element, calculate which square the cursor is over using mouse coordinates, show a CSS-positioned tooltip div
- On any input change: call `redrawCanvas()` — this should complete in under 16ms (single frame)

This eliminates 4,000+ DOM nodes and makes country/slider changes feel instant.
