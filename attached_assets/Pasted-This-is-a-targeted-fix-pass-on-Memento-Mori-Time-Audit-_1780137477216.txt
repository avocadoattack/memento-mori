FIX 1 — STEPPER BUTTONS RAPID-FIRE GLITCH

The + and − buttons in StepperSlider.tsx fire too fast when held, causing numbers and the grid
to flicker uncontrollably. The setInterval is firing at 80ms and likely accumulating multiple
intervals without cleanup.

Rewrite the hold behavior in StepperSlider.tsx:

```tsx
const intervalRef = useRef<ReturnType<typeof setInterval> | null>(null);
const timeoutRef  = useRef<ReturnType<typeof setTimeout>  | null>(null);

const stopHold = () => {
  if (timeoutRef.current)  { clearTimeout(timeoutRef.current);   timeoutRef.current  = null; }
  if (intervalRef.current) { clearInterval(intervalRef.current); intervalRef.current = null; }
};

const startHold = (direction: 1 | -1) => {
  stopHold(); // always clear any existing timers first
  applyStep(direction); // fire once immediately on press
  // After 450ms delay, begin repeating at 180ms — fast enough to feel responsive, slow enough to be controlled
  timeoutRef.current = setTimeout(() => {
    intervalRef.current = setInterval(() => applyStep(direction), 180);
  }, 450);
};

// applyStep clamps the new value to [min, max] before calling onChange
const applyStep = (direction: 1 | -1) => {
  onChange(Math.min(max, Math.max(min, parseFloat((value + direction * step).toFixed(10)))));
};
```

Attach:
- onMouseDown: startHold(direction)
- onMouseUp + onMouseLeave + onTouchEnd: stopHold
- useEffect cleanup: return () => stopHold()

This ensures: one click = one step, hold = 450ms pause then repeat at 180ms.
No interval accumulation is possible.

FIX 4 — SCROLL CHEVRON: VIEWPORT-SAFE POSITIONING

The ChevronDown scroll indicator appears off-screen on smaller laptops (MacBook 16") because
100vh includes browser chrome on some browsers/devices.

Replace the current positioning with a viewport-safe approach:

```css
/* In the hero section's wrapper or inline style: */
min-height: 100svh;  /* svh = small viewport height, excludes browser chrome */
/* Fallback for browsers that don't support svh: */
min-height: 100vh;

/* Use CSS custom property for safe cross-browser support: */
```

In the component:

```tsx
// Set CSS custom property on mount to capture actual visible height
useEffect(() => {
  const setVH = () => {
    document.documentElement.style.setProperty('--real-vh', `${window.innerHeight * 0.01}px`);
  };
  setVH();
  window.addEventListener('resize', setVH);
  return () => window.removeEventListener('resize', setVH);
}, []);
```

```css
/* In CSS: */
.hero-section {
  height: calc(var(--real-vh, 1vh) * 100);
}
```

The ChevronDown button (position: absolute, bottom: 32px) is already correctly positioned
relative to the hero section — it will now always stay within the visible viewport regardless
of screen size or browser chrome height.
