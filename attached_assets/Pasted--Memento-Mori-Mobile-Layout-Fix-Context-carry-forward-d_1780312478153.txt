# Memento Mori — Mobile Layout Fix

## Context (carry forward — do not revert these decisions)
- Framework: React + Vite (TypeScript) + Tailwind CSS
- NO GSAP — CSS keyframes + requestAnimationFrame only
- Canvas for LifeGrid — never DOM nodes
- NO `<input type="range">` — StepperSlider only
- Countdown MUST stay one row on desktop — flex-nowrap, tabular-nums, all 7 units
- Education displayed as calendar years — never instruction hours ÷ 8,760
- Grid is two-color only — warm beige base + red X on past weeks via ctx.stroke()
- sessionStorage not localStorage
- `--dvh` custom property for viewport height
- Column count via ResizeObserver on grid container, not window.innerWidth
- Decade labels are HTML `<span>` elements, not canvas text
- All calculation logic stays in useLifeCalc.ts — do not move it

---

## Goal

Make the app look great on mobile (≤767px / below Tailwind's `md` breakpoint) WITHOUT changing any desktop layout or behavior.

**Strategy: use `max-md:` Tailwind prefix exclusively for mobile overrides.** Never remove or modify an existing bare Tailwind class. Only add new responsive variants or `max-md:` overrides alongside existing classes.

After each file, output: ✅ [filename] — [what changed]

Stop and ask before: modifying useLifeCalc.ts, educationLevels.ts, or any file not listed below.

## Required Changes Per File

### 1. `src/components/Countdown.tsx`

**Problem:** 7 countdown units with `flex-nowrap` overflow on narrow screens (~390px).

**Fix:**
- On mobile (`max-md:`): allow the row to wrap into two lines using `max-md:flex-wrap max-md:justify-center`
- On mobile: reduce the font size of the numeric values and unit labels so the units are compact enough to ideally fit in two rows of 3–4 units each
- On desktop: behavior is UNCHANGED — keep `flex-nowrap` and all existing font sizes

### 2. `src/pages/Home.tsx`

**Problems:**
- Hero title `clamp(64px, 10vw, 120px)` — 64px minimum floor is too tall on mobile when combined with subtitle, countdown, and stat cards all needing to fit in one viewport
- The two stat cards (Free Years Remaining + Free Saturdays Remaining) displayed side-by-side may overflow or feel cramped on mobile
- The main page layout (ControlsPanel + content area) is likely side-by-side on desktop and needs to stack vertically on mobile

**Fix:**
- Hero title: add a mobile override to reduce the minimum clamp value to ~36px on mobile. If implemented as an inline style `clamp(64px, 10vw, 120px)`, replace with a CSS variable approach or add a `max-md:text-[36px]` class override
- Hero subtitle: scale down proportionally on mobile (if using clamp, add `max-md:text-[20px]` override)
- Free Years + Free Saturdays cards: ensure they stack vertically (`max-md:flex-col`) or reduce padding/font size so they fit comfortably side-by-side on mobile — whichever looks better given their content
- Main layout: if ControlsPanel and the main content area are in a side-by-side flex/grid row on desktop, add `max-md:flex-col` so they stack vertically on mobile, with ControlsPanel below the grid
- Ensure no element has a fixed `width` or `min-width` in px that exceeds 375px

### 3. `src/components/Quiz.tsx`

**Problems:**
- Quiz container likely has a fixed max-width that may not be full-width on mobile
- Input fields and buttons may have insufficient touch target height
- Advanced settings collapsible section may overflow horizontally

**Fix:**
- Quiz card/container: add `max-md:mx-4 max-md:w-[calc(100%-2rem)]` so it doesn't bleed off screen
- All primary action buttons (Calculate My Time, Skip to app): ensure minimum height of `44px` on mobile with `max-md:min-h-[44px]`
- M/F sex toggle buttons: minimum touch target `max-md:min-h-[44px] max-md:px-6`
- Advanced settings content: ensure full-width on mobile with no horizontal overflow

### 4. `src/components/LifeGrid.tsx`

**Problems:**
- Decade label `<span>` elements are absolutely positioned relative to canvas — their offsets are calculated based on row geometry. On mobile the column count changes (ResizeObserver handles this), but verify that decade label vertical centering recalculates correctly when the canvas resizes
- Coffin emoji ⚰️ HTML overlay positioning needs to stay anchored to the last canvas row on mobile

**Fix:**
- Verify the ResizeObserver callback triggers a full re-render of both the canvas AND the decade label spans when container width changes on mobile
- If decade labels use hardcoded pixel offsets that don't recalculate on resize, fix them to recalculate from the current `squareSize`, `gap`, `columns`, and `rows` values
- Coffin emoji: ensure its absolute position recalculates alongside canvas dimensions
- Add `max-md:text-[10px]` to decade label spans if they're currently larger and overlapping on narrow screens
- Do NOT change canvas rendering logic, color scheme, or animation

### 5. `src/components/ControlsPanel.tsx`

**Problems:**
- Panel likely assumes a minimum width; on mobile it needs to be full-width
- Section headers and parameter rows may be cramped
- The panel may have a fixed or min-width that causes horizontal scroll

**Fix:**
- Ensure the panel root element is `w-full` on mobile (`max-md:w-full`)
- Remove or override any `min-width` in px that would cause overflow on mobile
- Section padding: add `max-md:px-4` if sections have large horizontal padding
- Ensure the Reset to Defaults button is full-width on mobile: `max-md:w-full`
- Do NOT change any slider logic, default values, or StepperSlider behavior

### 6. `src/components/StepperSlider.tsx`

**Problem:** The `−` and `+` buttons likely have touch targets smaller than the 44×44px minimum recommended for mobile.

**Fix:**
- Add `max-md:min-h-[44px] max-md:min-w-[44px]` to both the `−` and `+` buttons
- Add `max-md:text-lg` to the button icons/labels so they're easier to tap
- The click-to-edit value field: ensure it's at least `max-md:min-w-[56px]` on mobile
- Do NOT change hold-to-repeat logic (450ms delay, 180ms repeat), step values, or visual bar

### 7. `src/components/StatsPanel.tsx`

**Problems:**
- Stat cards grid is probably 3 or 4 columns on desktop — this will be illegible on mobile
- The stacked "Where Your Life Goes" bar uses hover tooltips which don't work on touch devices
- Perspective text lines inside cards may overflow their containers on narrow screens

**Fix:**
- Stat cards grid: add `max-md:grid-cols-2` (or `max-md:grid-cols-1` for the highlighted Free cards if they're larger) so cards are readable on mobile
- Where Your Life Goes bar tooltips: add `onClick` toggle in addition to existing `onMouseEnter`/`onMouseLeave` — tapping a segment on mobile should show/hide its tooltip. Use a `useState` for `activeTooltipSegment` (index or null). On mobile the tooltip should appear above the tapped segment and dismiss on a second tap or when another segment is tapped
- Card text: add `max-md:text-sm` overrides for any stat values that would overflow on a 2-column mobile grid
- Do NOT change calculation display values, color tokens, or the bar's proportional widths

### 8. `src/index.css`

**Problem:** Horizontal overflow on mobile if any element exceeds viewport width.

**Fix:**
- Add the following if not already present:

```css
html, body {
  overflow-x: hidden;
  max-width: 100vw;
}
```

- Do NOT remove or change any existing CSS variables, color tokens, keyframe animations, or font imports
