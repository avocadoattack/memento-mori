# Memento Mori — Pre-Publish Audit & Cleanup Prompt

## Context (carry forward — do not revert any of these)

This is a React + Vite (TypeScript) SPA. The following decisions are **locked** and MUST NOT be changed under any circumstances:

- **No GSAP** — removed due to severe performance issues with 4,000+ DOM nodes. CSS keyframes + `requestAnimationFrame` only.
- **Canvas for LifeGrid** — never DOM nodes. Canvas is required for performance.
- **No `<input type="range">`** — drag is broken in this environment. The custom `StepperSlider` component is the only slider in the app.
- **Education displayed as calendar years** — never instruction hours ÷ 8,760 (that formula produces confusing output like "1.6 years").
- **Grid is two-color only** — warm beige base, past weeks get a red X via `ctx.stroke()`, current week gets 1px accent border + pulse. No category colors in grid.
- **Countdown is a single row** — `flex-nowrap`, `tabular-nums`, all 7 units. Never allow wrapping.
- **`sessionStorage` not `localStorage`** — quiz resets per tab by design.
- **`--dvh` custom property** for viewport height, set on mount + resize.
- **Column count via `ResizeObserver`** on the grid container — never `window.innerWidth`.
- **Decade labels are HTML `<span>` elements**, not canvas text.
- **All calculation logic stays in `useLifeCalc.ts`** — do not move formulas elsewhere.
- **No backend. No database. No new dependencies unless explicitly required.**
