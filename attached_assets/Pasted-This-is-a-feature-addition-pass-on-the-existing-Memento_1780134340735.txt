Replace them with a set of toggleable education level buttons. Each button can be toggled ON or OFF independently. The total education time is calculated as the sum of all active levels.

Use these education levels with their hardcoded hour values:

  {
    id: 'middle',
    label: 'Middle School',

  {
    id: 'highschool',
    label: 'High School',
    sublabel: 'Ages 14–18',
    years: 4,
    hoursPerDay: 6.5,
    daysPerYear: 180,
    // total: 4 × 180 × 6.5 = 4,680 hrs
  },
  {
    id: 'bachelors',
    label: "Bachelor's",
    sublabel: '4 years',
    years: 4,
    hoursPerDay: 5.0,
    daysPerYear: 220,
    // total: 4 × 220 × 5.0 = 4,400 hrs

    id: 'masters',

UI: render as a row of small pill/chip buttons. Active state: filled in the Education category color (#FFBE0B) with dark text. Inactive: ghost style (border only). Show below all buttons: "Total education time: [X,XXX] hours ([Y.Y] years)"

The totalSchoolHours passed to the calculation engine = sum of hours from all active levels.
